# 변경 내역 – 윈덤 로고 리뉴얼 및 메인페이지 색상 비율 적용 (2026-10-14)

## 1. 윈덤 강원고성 스타일 로고 제작 및 가독성 개선
- **레퍼런스 스타일 오마주**:
  - 사각 심볼 박스 내 해와 파도 엠블럼을 마스킹한 단색 모던 로고 디자인 적용.
  - 메인 워드마크를 국문 **'윈덤 강원고성'**과 영문 서브타이틀 **'WYNDHAM GANGWON GOSEONG'** 조합으로 재구성.
- **로고 시인성 및 크기 개선**:
  - `css/main.css`의 로고 높이(`--logo-h`)를 `46px`에서 `68px`로 확대하여 헤더 영역에서의 가독성 극대화.
  - `images/logo.svg` 내부 fill 색상을 사이트 딥 네이비(`rgb(32, 56, 75)`)로 통일하여 투명 헤더(화이트 필터) 및 스크롤 헤더(원색) 간 일관성 유지.

## 2. 메인페이지 색상 비율 가이드 기반 컬러 시스템 구축
사용자 제공 추천 컬러 팔레트 및 색상 적용 비율에 맞춰 `css/common.css`, `css/main.css`, `css/booking.css` 전반에 디자인 토큰을 반영:

| 컬러 명칭 | 색상 값 (RGB / HEX) | 목표 비율 | 사이트 내 주요 적용 영역 |
| :--- | :--- | :---: | :--- |
| **Pure White** | `rgb(255, 255, 255)` / `#FFFFFF` | **55%** | 사이트 기본 배경(`body`), ROOMS 및 POOL 섹션 배경, 객실·시설 카드 배경, 빠른 예약 바 글래스 배경 |
| **Ice Blue** | `rgb(243, 248, 252)` / `#F3F8FC` | **20%** | FACILITIES(부대시설) 섹션 배경, DINING 소프트 배경, 빠른 예약 필드 호버/포커스 배경 |
| **Sky Blue** | `rgb(184, 221, 242)` / `#B8DDF2` | **12%** | 히어로 배너 오버레이 중간 틴트, 섹션 Eyebrow 라벨, GNB 메뉴 밑줄 호버 효과, 스토리 섹션 통계 수치(`strong`), 카드 호버 외곽선 |
| **Ocean Blue** | `rgb(80, 125, 155)` / `#507D9B` | **8%** | 주요 CTA 예약 버튼(`btn-primary`), 객실 1박 시작 가격 표시, 예약 바로가기 링크 |
| **Deep Navy** | `rgb(32, 56, 75)` / `#20384B` | **5%** | 타이틀/헤드라인(`h1`~`h3`), 본문 텍스트, 푸터(Footer) 배경, 스크롤 헤더 텍스트 |
| **Silver Blue** | `rgb(214, 229, 239)` / `#D6E5EF` | **디테일** | 카드 테두리선, 섹션 구분선, 빠른 예약 입력 폼 보더 |
